# timeseries-notes

時系列データの読み方と、そこで使う指標の計算をまとめた静的サイト。

図はすべて実行時に計算して SVG で描いている。画像ファイルは 1 枚も置いていない。
指標の定義を変えれば、図も本文中の数値も一緒に変わる。

- ビルド不要・依存パッケージなし（素の ES Modules）
- 描画は自前の SVG レンダラ
- 系列データは決定論的な乱数から生成する合成データ

## 動かす

ES Modules を使っているので `file://` では動かない。静的サーバー越しに開く。

```bash
python3 -m http.server 8080
```

## テスト

DOM を使わない層（`domain` / `application` / `infrastructure/data`）は Node だけで検証できる。

```bash
node scripts/check.mjs
```

指標の計算、系列の集約、図の組み立てが対象。
「指標の系列長が元データと一致すること」もここで固定している——
ここがずれると、その足の時点では知り得ない値を参照することになるため。

## 構成

```
src/
├── domain/          外部に依存しない中心。値オブジェクトと計算のみ
├── application/     ユースケースと、外界との契約（ポート）
├── infrastructure/  ポートの実装（データ供給・SVG 描画）
└── presentation/    DOM を触る層と合成ルート
```

依存は常に内側を向く。`domain` は他のどの層も知らない。
詳細は [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 注意

図に使っているのは説明のために作った合成データで、実データではない。
特定の売買を推奨するものでもない。
